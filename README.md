## 🧩 Project Overview

Library Management System is a web application for managing book reservations, subscriptions and library operations.

Implemented functionality:

* Authentication and email confirmation
* Subscription management with Stripe integration
* Book catalog and availability management
* Shopping cart / reservation system
* Reservation validation based on subscription limits
* Delivery address and phone number form
* Azure deployment configuration
* CI/CD deployment pipeline
* Tooltip notifications and frontend validation
